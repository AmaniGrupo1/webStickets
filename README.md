# 📌 Descripción

**Amani Support Desk** es una plataforma web moderna diseñada para la gestión de incidencias y tickets de soporte técnico.

El sistema permite crear, visualizar, actualizar y administrar tickets en tiempo real gracias a la integración con **Firebase Realtime Database**, ofreciendo una experiencia rápida, moderna y totalmente responsive.

---

# ✨ Características principales

## 🎫 Gestión de tickets
- Creación de tickets de soporte
- Visualización detallada
- Eliminación de tickets
- Gestión automática de estados

---

## ⚡ Tiempo real con Firebase
Todos los cambios se sincronizan automáticamente:

- Nuevos tickets
- Actualizaciones de estado
- Eliminaciones
- Estadísticas en vivo

---

## 📊 Dashboard interactivo
Panel administrativo con estadísticas dinámicas:

- Total de tickets
- Tickets abiertos
- Tickets resueltos

---

## 🔄 Sistema de estados
Cada ticket puede cambiar entre:

| Estado | Descripción |
|---|---|
| 🟡 Abierto | Ticket recién creado |
| 🔵 En proceso | Ticket siendo gestionado |
| 🟢 Resuelto | Problema solucionado |
| ⚫ Cerrado | Eliminación automática |

---

## 🔍 Sistema de búsqueda y filtros
Incluye herramientas para:

- Buscar tickets por título
- Buscar por email
- Filtrar por estado

---

## 🌙 Personalización visual
La interfaz incluye:

- Tema claro y oscuro
- Cambio dinámico de iconos
- Animaciones modernas
- Diseño responsive
